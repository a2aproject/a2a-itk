[a2aproject/A2A `docs/assets/a2a_logo/`](https://github.com/a2aproject/A2A/tree/main/docs/assets/a2a_logo):

| file here | source |
| --- | --- |

| `apple-touch-icon.png` | `a2a_logo/icon/color/PNG/a2a_icon_color.png` |

`og.png` is a 1200x630 screenshot of `../tools/og.html`; edit that page and re-shoot it to regenerate the card.
